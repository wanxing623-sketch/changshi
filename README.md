# 识陷 · 公考政治理论训练

**识陷**是一款移动端优先、可离线使用的政治理论练习网页。它把“做错之后为什么错”作为训练重点：除了单项选择，还提供组合选择、判断、数字填空、间隔复习和限时组卷。

- 在线版：<https://wanxing623-sketch.github.io/changshi/>
- 无需账号、后端、构建工具或外部 CDN；学习记录只保存在当前浏览器。
- 题目与解析是原创学习内容，不冒充真题，也不复制开源仓库的题目。

## 适合练什么

题目按九类常见命题陷阱整理：绝对化表述、概念偷换、主次颠倒、范围扩大、主体错位、以偏概全、因果倒置、张冠李戴、数字与时间。内容覆盖马克思主义基本原理、毛泽东思想、中国特色社会主义理论体系、习近平新时代中国特色社会主义思想、党史党建、政治制度与法治、经济与社会、会议与关键时间。

| 题型 | 数量 | 练习重点 |
|---|---:|---|
| 单项选择 | 101 | 逐项识别概念、主体、范围和逻辑关系 |
| 组合选择 | 10 | 先判断每条表述，再选择正确项组合 |
| 判断 | 18 | 识别绝对化、限定条件和概念错位 |
| 数字填空 | 12 | 直接输入年份，屏幕数字键盘可点按 |
| **合计** | **141** | 题目按陷阱类型和主题交错安排 |

另有 **75 张背诵卡**、**23 条关键时间线**及 **10 组数字配对**。时间线侧重党史、重要会议与现代化目标的常见易混点。政治理论和时政内容会随考试范围变化；本项目不承诺覆盖最新年度时政，使用时请结合当年大纲和权威发布复核。

## 学习功能

- **混合练习**：题目交错呈现，减少只靠题型猜答案；每题答后立即给出陷阱、解析和解题提示。
- **每日 10 题**：到期复习优先，其次安排新题；题量短，适合每天完成一轮。
- **数字填空**：年份类题目可直接输入，也可用屏幕上的 0–9 数字键、退格和清空键输入。
- **限时测验**：从多类题目中组出 20 题，限时 20 分钟；交卷后统一查看结果与逐题答案。
- **错题回顾**：答错自动加入错题；连续答对两次后移出错题本。回答正确后还可自评“还不稳 / 记住了 / 很熟”，调整下一次复习间隔。
- **间隔复习**：本地记录每题的连续答对、复习间隔和难度系数；答错会缩短下次复习时间。排程参考 SM-2 的间隔重复思路，是为本项目简化重写的本地逻辑，不包含第三方题目或代码。
- **背诵卡**：先主动回忆再翻看答案，可按主题筛选并标记掌握情况。
- **避坑手册与数字时间线**：查看命题信号词、常见错法、易混配对及关键时间。
- **本地统计**：记录题库覆盖、累计正确率、陷阱掌握度、待复习数和近 7 天作答情况。

## 移动端与人因设计

- 移动端底部固定四项导航；桌面端改为侧边导航。
- 单题单屏，选项整行可点；答题后再展示解析，减少同时阅读的信息量。
- 练习中始终提供屏幕数字快捷键（1–4）；数字填空另配完整屏上数字键盘，不依赖系统软键盘。
- 触控目标至少 44 px；题卡支持左右滑动切题；横向筛选条可直接滑动。
- 中文优先使用系统字体，字号可放大，深浅色可切换；支持减少动态效果设置。
- 对错不只靠颜色区分，同时显示文字；键盘用户有清晰焦点提示。
- 页面没有装饰性英文小标题、插画式 hero 或表情符号堆叠。内容以题目和操作为主。

### 快捷操作

| 操作 | 作用 |
|---|---|
| `1`–`4` 或 `A`–`D` | 选择选项；屏幕上也有数字快捷键 |
| `Enter` | 确认答案；已看解析后进入下一题 |
| `←` / `→` | 上一题 / 下一题 |
| `S` | 收藏或取消收藏当前题 |
| 数字填空的 `0`–`9` | 输入数字；`退格` 删除一位，`清空` 清除输入，键盘 `Esc` 也可清空 |

本项目原先没有 OCR、语音识别或需要识别的远端服务。“识别速度慢”在当前静态练习中的对应问题是输入和答题反馈：答案在本地同步判定，按键后立即更新，不等待网络请求。若你指的是 OCR 识别图片/试卷，当前版本没有这项功能。

## 离线使用

- 本地使用：下载或克隆仓库后打开 `index.html`。不使用需要联网加载的字体、CDN 或 API。
- GitHub Pages：在线访问一次后，Service Worker 会缓存页面、样式、脚本和全部数据文件，之后可断网继续练习。
- 学习进度写入浏览器 `localStorage`，不会跨设备同步。清除浏览器数据会删除本机记录。
- 本地 `file://` 模式不支持 Service Worker，但页面本身仍可直接加载并练习。

也可启动任意静态文件服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages

仓库的 `.github/workflows/pages.yml` 在推送到 `main` 或手动触发时发布静态站点。GitHub 仓库的 Pages 来源应设为 **GitHub Actions**。所有静态资源使用相对路径，适用于项目页子路径部署。

## 开发与测试

项目没有构建步骤和运行时依赖。使用 Node.js 运行检查：

```bash
node --check app.js
for f in data/*.js; do node --check "$f"; done
node tools/balance.js
node test/smoke.js
node test/smoke.js migrate
```

`tools/balance.js` 用固定种子检查选择题答案分布；当前 111 道单选与组合题的 A/B/C/D 正确项分布为 **31 / 25 / 27 / 28**。测试还覆盖四种题型、数字键盘、错题复习、背诵卡、限时测验、主题字号和旧版本记录迁移。
